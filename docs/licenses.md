# Сторонние материалы и лицензии

Всё стороннее, что попало в проект: библиотеки, шрифты, иконки, изображения. Новая позиция дописывается сюда в момент добавления.

| Что | Где используется | Лицензия | Источник |
|---|---|---|---|
| Next.js | фреймворк | MIT | https://github.com/vercel/next.js |
| React | UI | MIT | https://github.com/facebook/react |
| Tailwind CSS | стили | MIT | https://github.com/tailwindlabs/tailwindcss |
| TypeScript | язык | Apache-2.0 | https://github.com/microsoft/TypeScript |
| Шрифт Onest | весь интерфейс | SIL OFL 1.1 | https://fonts.google.com/specimen/Onest |
| Lucide (`lucide-react`) | иконки | ISC | https://github.com/lucide-icons/lucide |
| Логотип (кристалл) | логотип, иконка сайта | собственный рисунок | `src/components/logo.tsx`, `src/app/icon.svg` |
| Drizzle ORM (`drizzle-orm`) | запросы к базе | Apache-2.0 | https://github.com/drizzle-team/drizzle-orm |
| Drizzle Kit (`drizzle-kit`, только разработка) | генерация миграций | MIT | https://github.com/drizzle-team/drizzle-orm |
| PGlite (`@electric-sql/pglite`) | локальная база PostgreSQL | Apache-2.0 / PostgreSQL | https://github.com/electric-sql/pglite |
| node-postgres (`pg`) | подключение к PostgreSQL на сервере | MIT | https://github.com/brianc/node-postgres |
| `server-only` | защита серверного кода от попадания в браузер | MIT | https://www.npmjs.com/package/server-only |
| tsx (только разработка) | запуск скриптов TypeScript | MIT | https://github.com/privatenumber/tsx |
