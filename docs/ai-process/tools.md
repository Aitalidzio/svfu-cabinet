# ИИ-инструменты и сервисы

Полный перечень того, чем пользовались, и для чего. Обязательная часть отчёта для жюри.

| Инструмент | Модель / версия | Для чего | С какого этапа |
|---|---|---|---|
| Claude Code в приложении Claude для Windows (вкладка Code) | Claude Opus 5.5 | Разбор положения конкурса, выбор стека, генерация кода, документация для ИИ-агентов, проверка работы | 07.11.2026 |
| Cursor (Agent) | Composer | Продолжение разработки с этапа заявок: проверка незавершённого кода Claude, доводка, документация, проверка сборки и браузера | 13.11.2026 |
| Playwright (временно, не в зависимостях проекта) | 1.56 | Скриншоты экранов заявок для отчёта (360 и 1280); после съёмки удалён из `package.json` | 13.11.2026 |
