# ИИ-инструменты и сервисы

Полный перечень того, чем пользовались, и для чего. Обязательная часть отчёта для жюри.

| Инструмент | Модель / версия | Для чего | С какого этапа |
|---|---|---|---|
| Claude Code в приложении Claude для Windows (вкладка Code) | Claude Opus 5.5 | Разбор положения конкурса, выбор стека, генерация кода, документация для ИИ-агентов, проверка работы | 07.11.2026 |
| Cursor (Agent) | Composer | Продолжение разработки с этапа заявок: проверка незавершённого кода Claude, доводка, документация, проверка сборки и браузера; маскот Таас | 13.11.2026 |
| Cursor GenerateImage | встроенная генерация | Черновые спрайты Тааса по наброску (потом заменены ручными SVG) | 21.11.2026 |
| Playwright (временно, не в зависимостях проекта) | 1.56 | Скриншоты экранов заявок, уведомлений, «Сегодня» и кабинета сотрудника (432×936 / 1280×800); растеризация SVG-спрайтов Тааса в PNG для отчёта; после съёмки удалён из `package.json` | 13.11.2026 |
| Python + fontTools (скрипты в `tools/`, не runtime) | 3.x | Проверка якутских букв в шрифтах и контраста палитры на этапе дизайна; в стек приложения не входит | 13.11.2026 |
