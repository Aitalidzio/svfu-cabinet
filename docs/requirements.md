# Чек-лист требований конкурса

Пересказ положения номинации «Вайб-кодинг» (задача «Цифровой деканат будущего»), разбитый на проверяемые пункты.
Отмечаем `[x]`, когда пункт сделан **и проверен руками**.

Сроки: работы принимают с 08.11.2026 19:00 до **22.11.2026 23:59 МСК**. Сайт должен работать до **28.11.2026** (день объявления итогов).
Отправленную работу можно заменить до дедлайна — оценивается последняя версия.

## 1. Обязательное ядро кабинета

- [x] **Вход и профиль.** Вход по логину и паролю. В профиле: ФИО, факультет (институт), направление, курс, группа.
- [x] **Расписание.** Занятия на сегодня и на неделю, аудитория, преподаватель. Переносы и изменения хорошо заметны.
- [x] **Успеваемость.** Оценки и зачёты по дисциплинам, сессия, понятный ответ на вопрос «как у меня дела с учёбой».
- [x] **Заявки и справки.** Онлайн-заказ справки или подача заявления, у заявки виден статус.
- [x] **Уведомления.** Новости и объявления деканата, напоминания о дедлайнах и изменениях.

Сценарий, который жюри почти наверняка пройдёт: **войти → расписание → оценки → подать заявку → увидеть её статус.**

## 2. Требования к прототипу

- [x] Это работающий сайт по ссылке в браузере, а не макет (Figma и картинки не считаются). *(https://argocabinet.tw1.su — Timeweb VPS, 22.11.2026)*
- [x] Стек подходит под задачу и масштабируется под разное число пользователей. *(Next.js + Postgres, решение №1–2, №4)*
- [x] Код написан ИИ-ассистентами, а процесс задокументирован. *(дневник, tools, скрины; PDF — `docs/ai-process/report.pdf`)*
- [x] Все основные сценарии работают на телефоне шириной от **360 px**. *(вход без горизонтального скролла; переключатели только в профиле/на входе; скрины до/после в `screenshots/15-mobile/`)*
- [x] Все данные вымышленные. Нет реальных ФИО, оценок, номеров зачёток, логинов и паролей. Прототип не подключён к настоящим системам вуза.
- [x] Видно, что это **концепт для конкурса**, а не официальный сервис СВФУ. *(ConceptNote на входе и в кабинете)*
- [x] Официальный логотип вуза не используется. Свой логотип может перекликаться с ним по идее, но не копирует его.
- [x] Сторонние библиотеки, шрифты, иконки и картинки используются только по разрешающей лицензии (список в [licenses.md](licenses.md)). *(Postgres/Caddy/Docker дописаны 22.11)*
- [x] Сайт открывается из России **без VPN** и работает до 28.11.2026. *(HTTPS на argocabinet.tw1.su; следить за балансом Timeweb)*
- [x] Для жюри есть минимум **два тестовых студента** с разными данными и аккаунт сотрудника. *(8 студентов в 4 институтах, у каждого своя группа; сотрудники `dekanat.imi` / `.fti` / `.fei` / `.uf`)*

## 3. Безопасность

- [x] Студент видит только свои данные. Чужой профиль или чужую заявку нельзя открыть, даже если подставить другой id в адрес. (сотрудник — только свой институт; чужой/чужой институт → один экран «Страница не найдена», без утечки существования)
- [x] Пароли не хранятся в открытом виде.
- [x] Ключи и пароли от сервисов (включая ИИ) не лежат ни в коде, ни в браузере пользователя. *(.env* в .gitignore; в репо только example)*

## 5. Критерии оценки (по 10 баллов, итог — среднее)

1. **Проработанность идеи.** Понятна проблема, сценарии построены вокруг реальных задач, ядро сделано полностью. Смелые идеи повышают оценку.
2. **Масштаб использования ИИ.** Продуманный процесс, качественные промпты, файлы для ИИ-агентов, работа с ошибками ИИ, ИИ для дизайна и контента, наглядное описание.
3. **Имплементация.** Всё работает без ошибок, данные сохраняются, есть мобильная версия, безопасность, работающие тестовые аккаунты.
4. **Качество.** Цельный современный дизайн, понятная навигация, продуманные пустые состояния, ошибки и загрузка, скорость и доступность.
