# Концепция кабинета

Что делаем, для кого и почему. Источник требований для экранов и базы данных: перед задачей по экрану сначала читаем этот файл.
Пункты со значком ⚠️ ещё не уточнены, их нельзя додумывать — нужно спросить команду.

## Что предлагает кабинет

1. **Одно место** вместо сайта, Excel, бота, чатов и очереди в деканат.
2. **Сначала главное.** Экран «Сегодня» отвечает на вопрос «что мне важно прямо сейчас».
3. **Деканат сообщает сам.** Каждое событие (справка готова, пару перенесли, новое объявление) превращается в уведомление.
4. **Цифры объясняют себя.** Вместо «42 балла» — «до допуска не хватает 3 балла».
5. **На трёх языках:** русском, якутском (саха тыла) и английском.

## Роли

- **Студент** видит только свои данные и расписание групп.
- **Сотрудник деканата** работает с заявками и объявлениями студентов своего института и меняет расписание его групп.

## Экраны студента

1. **Вход.** Логин и пароль, переключатель языка, плашка «Концепт для конкурса».
2. **Сегодня** (главный экран):
   - текущая или следующая пара: время, аудитория, преподаватель;
   - изменения в расписании на сегодня и завтра — сверху и заметно;
   - что «горит» по учёбе: не хватает до допуска, доступен автомат;
   - статусы активных заявок;
   - новые уведомления и ближайшие дедлайны.
3. **Расписание:**
   - «сегодня / завтра / неделя», по умолчанию своя группа;
   - можно открыть расписание любой другой группы, как в боте;
   - перенесённые и заменённые пары выделены цветом и показывают «было → стало»;
   - текущая пара отмечена «Идёт сейчас»; время считается по Якутску, где бы ни стоял сервер;
   - ⚠️ время пар взято типовое (1 пара 08:00–09:35, 2 — 09:50–11:25, 3 — 11:40–13:15, 4 — 14:00–15:35 …), нужно уточнить звонки СВФУ;
   - ⚠️ есть ли в СВФУ чередование недель (числитель / знаменатель)? Сейчас оно поддерживается, в демо одна чередующаяся пара в четверг у ПИ-24-1;
   - ⚠️ как в СВФУ обозначают корпуса в номере аудитории? Сейчас просто «ауд. 412».
4. **Успеваемость:**
   - дисциплины семестра: баллы, тип контроля, понятный статус (см. «Правила БРС» ниже);
   - для каждой дисциплины подсказка: «зачтено», «до зачёта не хватает 7», «до допуска не хватает 3», «автомат доступен», «для пятёрки на экзамене нужно 19 из 30»;
   - сессия: даты зачётов и экзаменов;
   - стипендия: назначена ли по итогам прошлой сессии и прогноз на текущую. Общее правило академической стипендии — без троек и долгов;
   - вкладка «Зачётная книжка»: итоги прошлых семестров, средний балл, стипендия по каждой сессии;
   - **тревога учитывает, сколько ещё можно набрать.** В середине семестра почти всё «не набрано», поэтому уровень зависит от того, какую долю оставшихся баллов нужно получить: до половины — спокойно, больше половины — «нужно внимание», больше, чем осталось, — «опасно» (плановых баллов не хватит). Для зачёта с оценкой цель — «4», потому что «3» лишает стипендии.
5. **Заявки.** Каталог справок и заявлений → короткая форма → карточка заявки со статусом и историей. Отдельного «трекера как у доставки» не делаем: хватает статуса и уведомления.
6. **Уведомления.** Лента с фильтрами «деканат / расписание / заявки», отметки «прочитано».
7. **Профиль.** ФИО, институт, направление, курс, группа, номер зачётки (всё вымышленное), язык, «Выйти», «Выйти на всех устройствах».

## Экраны сотрудника деканата

1. **Заявки студентов института:** очередь, фильтр по статусу, смена статуса с комментарием → студенту уходит уведомление.
2. **Объявления:** новое объявление для института, курса или группы → уведомления адресатам.
3. **Изменения расписания:** перенести или заменить пару → уведомление группе. Это закрывает проблему «о переносах узнаём от преподавателя».

## Правила БРС (балльно-рейтинговой системы)

Максимум за дисциплину — 100 баллов.

| Тип контроля | Правило |
|---|---|
| **Зачёт** | ≥ 60 баллов → «зачтено» |
| **Зачёт с оценкой** | 55–64 → 3, 65–84 → 4, 85–100 → 5, меньше 55 → не сдан |
| **Экзамен** | За семестр до 70 баллов, на экзамене до 30 |
| — допуск | ≥ 45 баллов за семестр |
| — автомат | ≥ 65 баллов за семестр → итоговая «4» без экзамена, по согласованию с преподавателем |
| — итог | Сумма «семестр + экзамен» по тем же порогам: 55–64 → 3, 65–84 → 4, 85–100 → 5. Отдельного минимума баллов на самом экзамене нет (по словам команды) |

Пример подсказки: за семестр 66 баллов → «автомат 4 доступен; для пятёрки на экзамене нужно 19 из 30» (66 + 19 = 85).

## Языки

- `ru` — основной, `sah` — якутский (саха тыла), `en` — английский.
- Переводится интерфейс. Названия дисциплин и тексты объявлений остаются на языке оригинала (русском).
- Якутский перевод делает ИИ, **проверяет Айтал** (капитан команды, знает якутский).
- Шрифт должен поддерживать якутские буквы: Ҕ ҕ, Ҥ ҥ, Ө ө, Һ һ, Ү ү.
