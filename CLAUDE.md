# Цифровой деканат СВФУ — концепт личного кабинета студента

@AGENTS.md

Прототип для хакатона, номинация «Вайб-кодинг», задача «Цифровой деканат будущего».
Работы принимают до **22.11.2026 23:59 МСК**, сайт должен работать до **28.11.2026**.
Все требования конкурса собраны в чек-лист: [docs/requirements.md](docs/requirements.md). Сверяйся с ним перед каждой задачей.
Почему выбраны именно эти технологии: [docs/decisions.md](docs/decisions.md).

## Как мы работаем

- Код пишет Claude Code. Человек ставит задачи, проверяет результат и **сам делает коммиты**.
- **Никогда не запускай `git commit`, `git push` и не меняй историю git.** В конце задачи предложи сообщение коммита на русском, например «Добавить форму входа».
- Одна задача — один небольшой осмысленный коммит. Рефакторинг и новую функцию не смешивай.
- После каждой задачи добавь запись в [docs/ai-process/journal.md](docs/ai-process/journal.md): что попросили, что сделано, какие ошибки ИИ нашлись и как их исправили, какие скриншоты стоит снять. Из этого дневника потом собирается отчёт для жюри.
- Новый внешний сервис или ИИ-инструмент → строка в [docs/ai-process/tools.md](docs/ai-process/tools.md).
- Новый шрифт, иконки, картинка или библиотека с особой лицензией → строка в [docs/licenses.md](docs/licenses.md).

## Стек

- Next.js 16.4 (App Router, папка `src/`, TypeScript, Turbopack), React 19, Tailwind CSS v4.
- **Эта версия Next.js новее данных обучения ИИ.** Перед тем как писать код, прочитай нужный гайд в `node_modules/next/dist/docs/`. Главные отличия:
  - `middleware.ts` теперь называется `proxy.ts`;
  - в `next.config.ts` включены `cacheComponents` и `partialPrefetching`, поэтому чтение `cookies()` и сессии должно стоять внутри `<Suspense>` (см. `01-app/02-guides/authentication-with-cache-components.md`).
- База данных: PostgreSQL через Drizzle ORM. Локально используется PGlite (Postgres прямо в процессе, ставить ничего не нужно), на сервере — настоящий PostgreSQL по `DATABASE_URL`. *Подключается на этапе «БД и вход».*
- Хостинг должен открываться из России без VPN. Варианты сравниваются в docs/decisions.md.

## Роли

- **Студент** видит только свои профиль, оценки, расписание своей группы, свои заявки и уведомления.
- **Сотрудник деканата** видит заявки студентов своего факультета, меняет их статус и публикует объявления.

## Безопасность (обязательно)

1. Данные читаются только через Data Access Layer (`src/server/dal/*`). DAL сам берёт текущего пользователя из сессии. Функции DAL **не принимают** `userId` от клиента.
2. Каждый Server Action и Route Handler заново проверяет сессию и роль. Спрятанная в интерфейсе кнопка — не защита.
3. Объект по id (`/requests/[id]`) запрашивается только с условием «владелец = текущий пользователь» или «сотрудник того же факультета». На чужой объект отвечаем 404, чтобы не раскрывать, что он существует.
4. Пароли хранятся только в виде хеша с солью (scrypt из `node:crypto`). Сессия — cookie с флагами httpOnly, Secure, SameSite=Lax; в БД лежит хеш токена сессии, а не сам токен.
5. Секреты хранятся только в `.env*` (они в `.gitignore`) и в переменных окружения сервера. Префикс `NEXT_PUBLIC_` для секретов запрещён. Шаблон без настоящих значений — `.env.example`.
6. В клиентские компоненты передаём только нужные поля (DTO), а не всю запись из БД.
7. На неверный логин и на неверный пароль показываем одно и то же сообщение. Попытки входа ограничены (rate limit).

## Данные

- Только вымышленные ФИО, оценки, номера зачёток и логины. Никаких реальных студентов и преподавателей.
- Расписание можно брать из открытых данных СВФУ, но имена преподавателей заменяем на вымышленные.
- На странице входа и в подвале каждой страницы есть плашка: «Концепт для конкурса. Не является официальным сервисом СВФУ».
- Официальный логотип СВФУ использовать нельзя. Логотип у нас собственный.

## Интерфейс

- Интерфейс на русском языке. Сначала делаем под телефон: всё должно работать на ширине **360 px**. Проверяем на 360, 768 и 1280.
- У каждого экрана есть состояния загрузки (скелетон), пустого списка и ошибки.
- Доступность: контраст не ниже AA, видимый фокус, подписи у полей, на телефоне зона нажатия не меньше 44 px.
- Шрифты и иконки — только с открытой лицензией (Google Fonts под OFL, Lucide под ISC).

## Команды

- `npm run dev` — dev-сервер на http://localhost:3000
- `npm run build` — продакшен-сборка. Запускай её перед тем, как предложить коммит заметного изменения.
- `npm run lint` — линтер.
