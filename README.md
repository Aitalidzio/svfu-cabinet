# Цифровой деканат СВФУ — концепт

> **Это концепт для конкурса**, а не официальный сервис Северо-Восточного федерального университета.
> Все ФИО, оценки, номера зачёток и учётные записи вымышлены.

Прототип личного кабинета студента: расписание, успеваемость, заявки и справки, уведомления деканата — всё в одном месте и удобно с телефона.
Сделан для хакатона, номинация «Вайб-кодинг», задача «Цифровой деканат будущего».

## Статус

🚧 Идёт разработка. Ход работы — в [дневнике процесса](docs/ai-process/journal.md).

## Как запустить локально

Нужен Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · PostgreSQL (Drizzle ORM).
Почему так — в [docs/decisions.md](docs/decisions.md).

## Как проект делается с ИИ

Код пишет ИИ-ассистент Claude Code. Команда ставит задачи, проверяет результат и сама коммитит изменения небольшими порциями.

- [CLAUDE.md](CLAUDE.md) — инструкции для ИИ-агента: правила безопасности, стек, порядок работы.
- [docs/requirements.md](docs/requirements.md) — требования конкурса в виде чек-листа.
- [docs/ai-process/](docs/ai-process/) — дневник промптов и решений, список инструментов, скриншоты.
- [docs/licenses.md](docs/licenses.md) — сторонние материалы и их лицензии.
